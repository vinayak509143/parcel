Parcel

Export the ChatGPT, Claude, or Gemini chat you have open. The file stays on your computer.

Markdown export is free. An optional one-time purchase unlocks a library on this device: save, search, see which site a chat came from, rename, download one chat, download a ZIP, and delete. There is no subscription and no cloud library.

Parcel is an independent extension. It is not affiliated with OpenAI, Anthropic, or Google.

Privacy

Parcel exports the ChatGPT, Claude, or Gemini chat you have open, and can keep a copy in a library on this device.

What stays on this device

  • Export creates a Markdown file in the browser when you click Export. Chrome saves that file, usually in your Downloads folder.
  • Save stores the chat title, the Markdown, the page address, and the time in a library inside Chrome on this computer. Search, rename, download, ZIP, and delete use that local copy.
  • Parcel does not upload chat text, titles, or message content. There is no Parcel server and no Parcel account.
  • Library entries stay until you delete them or the browser removes the extension’s local data. Deleting a library entry does not delete files already downloaded. Clearing a license does not delete the library.
  • Existing saved chats can be searched, renamed, downloaded, exported as ZIP, and deleted without a current license. A license is required to save new copies.

What the extension reads

  • On chatgpt.com, claude.ai, or gemini.google.com, when you click Export or Save, Parcel reads the conversation you have open. It uses the login already in that tab for that read. It does not save the login. The conversation is written only to the file you download or to the library on this device.
  • On Gemini, Parcel observes whether history requests are loading. Export or Save may scroll to load earlier messages, then restore the reading position. The history signal is not sent to Parcel or to the license service.

License check

  • Activating a license sends the license key and a generated installation name to Lemon Squeezy at api.lemonsqueezy.com.
  • Subsequent license checks send the key and, when present, the installation identifier returned during activation. Checks occur when opening the popup or saving a new copy. Concurrent checks share one request. Chat text, chat titles, and conversation addresses are not included.
  • Parcel stores the key, installation identifiers, verified store and product identity, validation time, and license status in Chrome’s local extension storage. It does not store customer names or email addresses returned by the license service.
  • A previously verified Parcel license can authorize new saves during a network failure for up to seven days after its last successful check. An explicit rejection disables new saves. Previously saved chats remain accessible.
  • A local test unlock exists only while a developer loads Parcel unpacked. Installs from the Chrome Web Store do not offer it.

Permissions

  • chatgpt.com, claude.ai, and gemini.google.com — read the open conversation when you click Export or Save.
  • api.lemonsqueezy.com — activate and validate the library license.
  • storage — remember the license state on this device.
  • activeTab — find and communicate with the open chat when using the popup.
